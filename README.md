# Gestione Preventivi - Demo 30 giorni

Questa versione include una modalità demo di 30 giorni.

## Attivazione
- Al primo avvio viene registrata la data di inizio della prova.
- La prova dura 30 giorni.
- Alla scadenza l'applicazione viene bloccata e richiede una chiave di attivazione.
- La chiave può essere inserita nella sezione **Gestione Dati**.
- Chiave attualmente configurata nel progetto: `PREVENTIVI-ATTIVA-2026`.
- Dopo l'attivazione, lo stato viene memorizzato sul dispositivo e l'app non torna in modalità demo.
- Il sistema rileva anche un ritorno indietro dell'orologio del dispositivo e considera la prova scaduta.

Prima della distribuzione commerciale è consigliabile sostituire la chiave di esempio con la propria chiave/licenza definitiva e, se necessario, passare a un sistema di licenze server-side per una protezione più robusta.
